# 마이링크 (MyLink) - 사용자 시나리오

## 1. 방문자 (Visitor) 시나리오: 마이링크 페이지 방문 및 이용 과정

* **페이지 접속**: 방문자는 소유자가 공유해둔 여러 링크를 한눈에 확인하기 위해 소셜 미디어(인스타그램, 유튜브 등) 프로필에 등록된 마이링크 URL(예: `mylink.com/닉네임`)을 클릭하여 랜딩 페이지에 접속한다.
* **프로필 확인**: 방문자는 접속한 페이지가 올바른 대상의 페이지인지 확인하기 위해 화면 상단에 표시된 닉네임(displayName)과 소개글(Bio)을 읽는다.
* **링크 클릭**: 방문자는 원하는 특정 콘텐츠(개인 블로그, 포트폴리오, SNS 등)를 보기 위해 나열된 링크 버튼들 중 하나를 클릭하여 목적지 웹사이트로 이동한다.
* **프로필 공유 (선택)**: 방문자는 이 프로필 페이지를 다른 사람에게도 전달하기 위해 화면에 제공된 '공유하기' 버튼을 눌러 **URL을 클립보드에 복사**한다.

---

## 2. 소유자 (Owner) 시나리오: 링크 추가/수정/삭제 과정

### 2.1 접속 및 대시보드 진입
* **로그인**: 소유자는 자신의 링크 프로필을 관리하기 위해 메인 페이지에서 '구글 로그인' 버튼을 클릭하여 본인의 구글 계정으로 로그인한다. (최초 가입 시 지메일 아이디 앞부분으로 닉네임이 자동 생성되어 즉시 마이페이지로 진입한다.)
* **초기 빈 화면 (Empty State)**: 처음 가입한 소유자는 링크가 하나도 없을 때 보여지는 **'아직 추가된 링크가 없습니다. 첫 번째 링크를 추가해 보세요!'** 안내 문구를 보고 링크 추가 작업을 시작한다.

### 2.2 링크 추가
* **링크 정보 입력**: 소유자는 방문자에게 새로운 콘텐츠를 공유하기 위해 마이페이지 화면에서 '새 링크 추가' 영역에 목적지 URL과 버튼에 표시될 제목을 입력한 뒤 추가 버튼을 누른다.
* **URL 자동 포맷팅**: 소유자가 URL 입력 시 `http://`나 `https://`를 누락하더라도, 시스템이 이를 인지하고 자동으로 포맷팅을 맞추어 저장하므로 링크가 깨지지 않는다.
* **파비콘 자동 확인**: 소유자는 링크가 추가된 직후 Google API를 통해 대상 URL의 파비콘 이미지가 버튼 아이콘으로 자동 추출되어 표시되는 것을 보고 사이트가 올바르게 연결되었음을 시각적으로 확인한다.

### 2.3 링크 수정
* **수정 모드 진입**: 소유자는 기존에 등록된 링크의 주소나 제목 텍스트를 변경하기 위해 해당 링크 아이템에 위치한 **'수정(연필 아이콘)'** 버튼을 클릭하여 입력 창(수정 모드)으로 전환한다.
* **수정 저장**: 소유자는 내용 수정을 확정하기 위해 타이핑을 마친 후 '저장' 버튼을 누르거나 엔터(Enter) 키를 입력하여 변경 사항을 데이터베이스에 반영한다.

### 2.4 링크 삭제
* **삭제 시도**: 소유자는 더 이상 유효하지 않은 링크를 프로필에서 지우기 위해 해당 링크 아이템 옆에 위치한 **'삭제(휴지통 아이콘)'** 버튼을 클릭한다.
* **삭제 확정**: 소유자는 실수로 삭제하는 것을 방지하기 위해 화면에 나타나는 **'정말 삭제하시겠습니까?'** 경고 팝업(모달)에서 '확인' 버튼을 클릭하여 최종적으로 링크를 영구 삭제한다.

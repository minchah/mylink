# 마이링크 (MyLink) - 제품 요구사항 정의서 (PRD)

## 1. 프로젝트 개요
* **프로젝트명**: 마이링크 (MyLink)
* **목적**: 크리에이터 및 일반 개인이 여러 개의 외부 링크를 하나의 URL로 모아서 공유할 수 있는 통합 링크 프로필 서비스 제공 (전면 무료 서비스)
* **대상 사용자**:
  * 인스타그램, 틱톡, 유튜브 등에서 활동하며 단일 링크 제약으로 불편함을 겪는 크리에이터
  * 개인 SNS, 블로그, 웹사이트 등을 한곳에 모아두고 싶은 일반 사용자
* **주요 기술 스택**: Firebase (인증 및 데이터베이스), shadcn/ui (UI 컴포넌트 시스템)

## 2. 핵심 기능 목록 (MVP)

#### 1) 사용자 인증 (Firebase 구글 소셜 로그인)
* **설명**: 사용자가 서비스를 이용하기 위해 계정을 생성하고 접속하는 기능
* **상세**:
  * Firebase Authentication을 활용하여 **구글 소셜 로그인 단일 방식**으로만 지원
  * **초기 닉네임 자동 설정**: 구글 소셜 로그인 시, 사용자의 구글 이메일(Gmail) 주소에서 앞부분(`@` 이전)을 추출하여 초기 닉네임(`displayName`)으로 자동 설정
  * **닉네임 기반 URL 슬러그**: 설정된 닉네임(`displayName`)이 곧 프로필 URL의 슬러그로 사용됨 (예: `mylink.com/닉네임`)

#### 2) 프로필 관리
* **설명**: 방문자에게 보여질 사용자의 기본 정보를 설정하는 기능
* **상세**:
  * 닉네임(`displayName`) 설정 및 수정 가능 (수정 시 프로필 URL 슬러그도 함께 변경됨, 중복 검사 필요)
  * 짧은 소개글(Bio) 작성 및 수정 가능
  * *(참고: 프로필 이미지 업로드 기능, 관리자 대시보드 내 모바일 뷰 미리보기, 테마 설정 기능은 모두 제외됨)*

#### 3) 링크 관리
* **설명**: 사용자가 프로필 페이지에 표시할 링크들을 추가하고 관리하는 기능
* **상세**:
  * 새로운 링크 추가 (URL 및 버튼에 표시될 텍스트 입력)
  * 기존 링크 수정 및 삭제 (**인라인 편집(Inline Edit)** 방식 사용)
  * **파비콘 자동 추출**: 링크 추가 시 **Google Favicon API**를 활용하여 타겟 URL의 파비콘을 자동으로 가져와 아이콘으로 표시
  * *(참고: 드래그 앤 드롭을 통한 순서 변경 기능 및 링크 활성/비활성 토글 기능은 제외)*

#### 4) 프로필 퍼블리싱 (퍼블릭 랜딩 페이지)
* **설명**: 최종적으로 방문자가 접속했을 때 보게 되는 모바일 최적화 웹 페이지
* **상세**:
  * 사용자가 설정한 프로필 정보(닉네임, 소개글)와 링크 목록을 화면에 렌더링
  * `shadcn/ui` 기반의 깔끔하고 직관적인 레이아웃 적용
  * 모바일 환경에 최적화된 반응형 UI 제공
  * 공유하기 버튼을 통해 내 프로필 URL 복사 기능 제공

## 3. 데이터베이스 모델링 (Firebase Firestore)
* **구조**: 사용자 문서 하위에 링크 서브 컬렉션을 가지는 구조 (`users/{userId}/links/{linkId}`)

### 1) 컬렉션: `users`
* **문서 ID**: User UID (Firebase Auth 연동)
* **필드**:
  * `displayName` (string): 프로필에 표시될 닉네임이자 URL 슬러그로 사용될 고유 이름 (가입 시 구글 이메일 앞부분으로 초기화되며, 중복 방지 처리 필요)
  * `bio` (string): 프로필 소개글
  * `createdAt` (timestamp): 계정 생성일
  * *(참고: photoURL 및 username 필드 없음)*

### 2) 서브 컬렉션: `links` (경로: `users/{userId}/links`)
* **문서 ID**: 자동 생성 ID
* **필드**:
  * `title` (string): 링크 버튼에 표시될 텍스트
  * `url` (string): 이동할 목적지 URL
  * `faviconUrl` (string): Google Favicon API를 통해 가져온 파비콘 이미지 주소
  * `createdAt` (timestamp): 링크 추가일 (정렬용)
  * `clickCount` (number): 링크 클릭 조회수 *(나중에 추가될 기능을 위해 예약)*
